#  Modelos, Grid y CSS puro

En este taller aprendimos los diferentes **modelos y grid** disponibles en CSS, además de distintos estilos y maneras de darle un buen diseño a nuestra página web usando **solo CSS puro**. También integramos lo aprendido en el **Taller 1**.

🔗 **Demo (GitHub Pages):** https://22carlosnarvaez.github.io/taller-2/

---

## 🎯 Objetivos del taller

- 📦 Comprender el modelo de caja y los modelos de maquetación en CSS.
- 🧱 Construir layouts con **grid**.
- 🖌️ Aplicar estilos y diseños sin frameworks, solo con CSS puro.
- 🔗 Integrar los conocimientos del Taller 1 en un sitio de varias páginas.
- 🚀 Publicar el proyecto con GitHub Pages.

---

## 📁 Estructura del proyecto

```
taller-2/
├── assets/           # Recursos estáticos (estilos, imágenes, multimedia)
├── index.html        # Página principal
├── curriculum.html   # Hoja de vida
├── contacto.html     # Formulario / datos de contacto
├── grid.html         # Práctica de maquetación con grid
├── multimedia.html   # Imágenes, audio y video
└── README.md         # Documentación del proyecto
```

| Archivo | Descripción |
|---|---|
| 🏠 `index.html` | Página de inicio del sitio. |
| 📄 `curriculum.html` | Presentación de la hoja de vida. |
| ✉️ `contacto.html` | Información y formulario de contacto. |
| 🧱 `grid.html` | Ejercicios con los distintos modelos de grid. |
| 🎬 `multimedia.html` | Integración de contenido multimedia. |
| 🗂️ `assets/` | Hojas de estilo (`style.css`) y demás recursos. |

## 🚀 Cómo ejecutarlo localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/22CarlosNarvaez/taller-2.git
   ```
2. Entra a la carpeta:
   ```bash
   cd taller-2
   ```
3. Abre `index.html` en tu navegador (o usa la extensión **Live Server** de VS Code).

---

## 📚 Aprendizajes

- El diseño con CSS puro da control total, pero requiere más código que un framework.
- Grid facilita crear estructuras de varias columnas y filas de forma ordenada.
- Separar los estilos en `assets/` mantiene el HTML limpio y fácil de mantener.
